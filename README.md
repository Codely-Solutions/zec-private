# ZEC Private Android

An independent Android Zcash wallet with shielded payments, NEAR Intents swaps, Tor, and hardware/view-only wallet support.

## Install

Download **zec-private-latest.apk** from the [latest release](https://github.com/Sammy-Lastre/zec-private/releases/latest). Requires an **ARM64 Android device**. See the [wallet guide](docs/WALLET-GUIDE.md#installation-and-updates) to verify the download.

**Automatic updates:** [Add ZEC Private to Obtainium](https://apps.obtainium.imranr.dev/redirect?r=obtainium%3A%2F%2Fapp%2F%257B%2522id%2522%253A%2522com.personal.zecprivate.foss%2522%252C%2522url%2522%253A%2522https%253A%252F%252Fgithub.com%252FSammy-Lastre%252Fzec-private%2522%252C%2522author%2522%253A%2522Sammy-Lastre%2522%252C%2522name%2522%253A%2522ZEC%2520Private%2522%252C%2522additionalSettings%2522%253A%2522%257B%255C%2522includePrereleases%255C%2522%253Afalse%252C%255C%2522includeDrafts%255C%2522%253Afalse%252C%255C%2522fallbackToOlderReleases%255C%2522%253Afalse%252C%255C%2522apkFilterRegEx%255C%2522%253A%255C%2522%255Ezec-private-latest%255B.%255Dapk%2524%255C%2522%252C%255C%2522autoApkFilterByArch%255C%2522%253Atrue%252C%255C%2522trackOnly%255C%2522%253Afalse%257D%2522%257D). [Install Obtainium](https://obtainium.imranr.dev/) if needed.

Install updates over the existing app. Keep your recovery phrase and birthday safe before troubleshooting; uninstalling can erase your wallet data.

## Use the wallet

- Send, receive and recover Zcash, redeem gifts, or swap supported assets.
- ZEC Private adds no app or affiliate fee. Network and provider costs still apply; review the amounts before confirming.
- Tor protects sensitive wallet and provider requests when enabled. Public block downloads remain direct. See [privacy](docs/PRIVACY.md) for what providers can see.

Read the [wallet guide](docs/WALLET-GUIDE.md) for payments, swaps and recovery, or [support development](docs/DONATIONS.md).
