# Contributing

Bug reports, feature suggestions and questions are welcome through [GitHub Issues](https://github.com/Codely-Solutions/zec-private/issues/new/choose). Search existing issues first and use the appropriate template. For bugs, include the app version, Android version, reproduction steps and expected versus actual behavior.

The project is maintained directly; pull requests are not accepted. Share proposed changes in an issue for discussion.

Keep recovery phrases, private/viewing keys and personal wallet data out of issues. Report vulnerabilities through the [private security reporting route](../.github/SECURITY.md).
